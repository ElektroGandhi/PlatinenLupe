# bambu_p1s_template.json

Printer, process and filament settings for a Bambu Lab P1S with PLA, resolved from the system profiles that ship
with [Bambu Studio](https://github.com/bambulab/BambuStudio). Bambu Studio is licensed under the
**GNU AGPL-3.0**; this file is derived from its profile data and is distributed under the same licence, not under the
MIT licence of the rest of this repository. Source: `resources/profiles/BBL/` in the Bambu Studio repository.

It is only used by `bambu_3mf.py` to write a 3MF project that Bambu Studio opens with sensible settings. Any other
slicer can use the STL files in `../print/` instead.
