# Security

- The hotspot starts with a **known default password** (`platinenlupe`). Change it on first use — the page reminds
  you until you do. A factory reset (hold FLASH/BOOT for 5 s at power-on) restores the default.
- The device page has no login. Anyone inside the hotspot or your home network can watch and change settings.
  That is by design for a workbench tool; do not expose the board or the server to the internet.
- The loupe's own WiFi password is derived from its Bluetooth advertisement — that is how the loupe is built, not
  something this project can change.

Found a problem? Please open an issue — or, for anything sensitive, contact the maintainer privately first.
